Updater messages

  • Not configuredThe build doesn't know its repository. Build in GitHub Actions or set ORYVEX_UPDATE_REPO.
  • No release yetNothing is published. Push to main or run the Release workflow.
  • Could not reach GitHubBoth GitHub routes failed. Wait a minute, or bind a GITHUB_TOKEN secret.
  • Not attached to releaseThe release has no worker-single-file.js. Re-run the Release workflow.
  • Worker not foundThe Worker name is wrong, or the token lacks Workers Scripts: Edit.

Clients show -1 ping

Check the app uses TLS port 443 (or another TLS port) with ALPN http/1.1 for WebSocket nodes, and that the kill switch is off. Try the XHTTP node on networks that break WebSockets.
