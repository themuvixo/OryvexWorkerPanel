Does it cost anything?

No. It runs on Cloudflare's free Workers plan. The free plan allows 100,000 requests a day; the panel's CF daily meter shows how much you've used.

Can I sell access?

No. The software, deployments and the links it generates are for personal, educational and non-commercial use only. See the LICENSE.

How many subscribers?

Up to 200 per Worker, each with their own limits, expiry and keys.

Will updating erase my users?

No. Users live in KV, not in the code. The updater keeps every binding, variable and secret. Export a backup first if you want extra peace of mind.

I forgot the admin password

There's no reset link, by design. Deleting the nl:state:v2 key in your KV namespace re-runs setup, but it also clears subscribers and settings, so restore a backup afterwards. Keep a backup handy.

Can I run my own fork?

Yes. Fork, enable Actions and Pages (source: GitHub Actions), push to main. Your fork gets its own releases, docs site and an updater that points at it.
